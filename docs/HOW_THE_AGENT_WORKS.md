# How the agent works

This example uses: “Remind me tomorrow at 5pm to send the draft.” The provider resolves the relative time using the current local date/time and `Asia/Kolkata` supplied on every request.

1. The user opens Ask Curie from the right-click menu or `Ctrl+Option+A`. Both call the same `openAskWindow` function. The window uses the existing calm owner and restores the previous calm mode when it closes unless the user changed calm manually.
2. Enter sends the message through `ask-window-preload.js`. The main process rejects empty or oversized messages and rejects another request while one is running.
3. The controller supplies current date, time, timezone, and at most 50 open tasks with only id, title, due time, and status. Gemini 3.5 Flash runs first and Groq is the fallback. The Gemini model default is defined once in settings and shared by the key-test window and agent; Gemini does not silently switch among models. Gemini requests have a 30-second timeout and the configured 512-token agent output cap. The key-test request uses a 1024-token cap so the model has room for internal thinking as well as its short visible answer. Google documents that thinking uses output tokens; a real owner test observed 103 thinking tokens and 9 visible output tokens. Both providers' requests count against the stored 400/day and 20/rolling-minute limits.
   Gemini 3.5 Flash uses the documented OpenAI-compatible `extra_body.google.thinking_config.thinking_level: "low"` setting. Google describes low as latency-oriented and appropriate for agentic tasks; minimal is optimized for simple chat. Prompt, output, and thinking token counts are logged per provider call, without prompt or reply text. See Google's [OpenAI compatibility guide](https://ai.google.dev/gemini-api/docs/openai) and [Gemini thinking guide](https://ai.google.dev/gemini-api/docs/thinking).
4. The model proposes `add_task` with a reminder ISO value such as `2026-10-29T17:00:00+05:30`. The tool validates title length and ISO timestamps, but the task is not written yet.
5. The window shows the proposed action in human language and offers Confirm all / Cancel all. Several writes from one response are grouped. Waiting for the user is asynchronous and excluded from provider timeout and the five-iteration loop cap. Closing the window, Escape, or five minutes without an answer cancels.
6. Confirm executes each validated write through the existing task service. A task and its optional reminder are written together. Cancel sends `user cancelled` to the model, which can respond without claiming success.
7. The existing reminder scheduler handles that reminder. Explicit reminders fire at their chosen time even in quiet hours and catch up after sleep. Automatic nudges remain local and continue to obey quiet hours and their three-per-day default cap.
8. Only six tools are available: `add_task`, `list_tasks`, `complete_task`, `delete_task`, `set_reminder`, and `start_focus`. List and focus start are immediate; the four task writes require confirmation. Invalid or unknown calls get one retryable error; a repeated identical invalid call stops the loop. The loop caps at five provider responses.

When Gemini returns function calls, Curie preserves the assistant `tool_calls` message, including `extra_content.google.thought_signature`, unchanged for the next request. Gemini 3 requires the thought signature on the first function-call part in a response. If it is absent, Curie stops before executing a tool and reports a clear error. See Google's [thought signatures guide](https://ai.google.dev/gemini-api/docs/generate-content/thought-signatures).

The provider fixtures in tests follow provider documentation schemas, not live captured responses. Tests cover JSON-string and object arguments, omitted IDs, multiple calls, empty tool-call content, invalid/truncated JSON, finish reasons, safe errors, fallback, caps, confirmation, reminder catch-up, and Gemini thought signatures. The app does not log API keys, user messages, or model replies.

## Code to follow

Read `src/agent/controller.js`, then `src/agent/loop.js`, `src/agent/providers.js`, `src/agent/prompts.js`, and `src/agent/tools.js`.
